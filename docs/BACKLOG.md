# 후속 작업 목록 (Backlog)

## 🐞 버그

### B1. 휴대폰 골방에서 말씀 책을 열면 찬양 플레이어가 화면 왼쪽 밖으로 밀려남 (2026-11-11 사용자 제보)
- **환경:** 안드로이드 휴대폰 (세로, 약 412px 폭), 골방 안, 찬양 플레이어가 골방 크기 조절 모드(작게/보통/크게)인 상태에서 상단 "책"(말씀 책) 열기
- **증상**
  1. 찬양 플레이어가 **왼쪽 위로 밀려서 일부가 화면 밖으로 잘림** (영상의 왼쪽 절반 이상이 보이지 않음)
     - **유튜브 정책 위험:** 재생 중에는 200×200 이상이 화면에 보여야 함
  2. 잘린 플레이어가 **장소 카드("지금 있는 곳")를 덮음**
  3. 플레이어 아래쪽(크기 버튼 "보통/크게")이 말씀 책 시트 위에 겹침
  4. 말씀 책 시트 위쪽에 제목이 없고 "닫기"만 보임 (헤더 공간이 플레이어에 가려졌을 가능성)
- **추정 원인:** 시트가 열릴 때 플레이어를 compact dock으로 옮기는 규칙과, 골방 전용 크기·위치 규칙(`#worship.room.room-*`)이 충돌함. 휴대폰 + 골방 + 시트 열림 조합의 CSS 우선순위 문제로 보임
- **수정 방향:** 골방에서 시트가 열리면 플레이어를 **화면 안의 compact 위치**(오른쪽 위 200×200, 또는 시트 위 상단 고정)로 옮기고, 골방 크기 버튼은 숨김. 360·390·412px에서 "플레이어가 화면 안에 있고 200×200 이상"인지 자동 테스트 추가
- **상태:** ✅ 수정됨 (B1 패치) — 골방에서 시트가 열리면 플레이어가 `room-sheet` 상태 하나로만 배치됨: 영상만 200×200(휴대폰)/356×200(태블릿·데스크톱), HUD 아래 오른쪽, 시트는 그 아래(또는 왼쪽)에. 크기 버튼은 숨기고 닫으면 골방 크기·작게 상태 복원. `client/scripts/b1-test.mjs`로 360·390·412·iPad Air·데스크톱 × 작게/보통/크게/mini × 모든 시트 검사

### B2. 말씀 책 날짜 이동 버튼 방향이 헷갈림
- **증상:** 왼쪽 버튼이 "‹ 다음 날", 오른쪽 버튼이 "이전 날 ›"이라 화살표 방향과 의미가 반대로 느껴짐
- **수정 방향:** 왼쪽 "‹ 이전 날", 오른쪽 "다음 날 ›"으로 (또는 최신이 오른쪽). M10에서 말씀 책 탭이 바뀌므로 함께 확인
- **상태:** ✅ 수정됨 (B1 패치) — 왼쪽 "‹ 이전 날"(더 오래된 날), 오른쪽 "다음 날 ›"(더 최근 날). 쪽수는 1(가장 오래된 날)…N(최신)으로 같은 방향, 최신 장에서는 "다음 날", 가장 오래된 장에서는 "이전 날"이 꺼짐 (스와이프 이동은 없음). m10-test에 검사 추가

### B3. 도서관 사진(스크린샷)이 백업되지 않음
- `backup.mjs`는 DB만 복사하고 `/data/screenshots`의 사진 파일은 복사하지 않는다. 복구하면 사진이 404로 뜬다
- **수정 방향:** 백업할 때 사진 폴더도 함께 보관한다 (보관 개수와 삭제 동기화 포함)
- **상태:** ✅ 수정됨 (L-B) — `backup.mjs`가 DB 백업과 함께 `backups/screenshots/`에 사진 **증분 미러**를 유지한다 (새 파일만 복사, 원본에서 지워졌고 남아 있는 어떤 백업 DB도 쓰지 않는 사진은 미러에서 삭제 → 약 14일 안에 백업에서도 사라짐). 복구는 `node server/scripts/backup.mjs --restore-photos <백업 파일>`. `deploy/README.md` 4장, 개인정보처리방침 보관 기간 갱신. `lb-test`의 backup 단계가 두 번 실행·삭제 반영·복구 후 사진 200을 확인

### B4. 도서관 안에서 어딘가에 빠져서 못 나감 (2026-11-12 사용자 제보, 안드로이드)
- **원인:** ① 벽 옆 가구(구석 화분, 서쪽 벽 발자취 서가)의 충돌 밀어내기가 플레이어를 바닥 밖(높이 -10)으로 밀어내면, 그 뒤 모든 이동이 "걸을 수 없는 곳"으로 거부돼 갇힘 ② 도서관에 들어가기 직전에 보낸 위치에 대한 서버의 늦은 `correct`(월드 좌표)가 도서관 안에서 적용되면 바닥 밖으로 순간이동해 같은 상태가 됨
- **상태:** ✅ 수정됨 (L-B) — 밀어내기가 바닥 밖으로 나가면 제자리 유지, 실내에서는 순간이동·일어서기가 가장 가까운 빈 바닥으로, 도서관 안에서 월드 좌표 `correct`는 무시, 바닥 밖·가구 안이면 자동 복구, 방향을 2초 이상 눌러도 못 움직이고 가구 안이면 빈자리로 옮김. 장소 카드에 항상 **↩ 문으로 나가기**. `lb-test`의 walk 단계가 실제 이동 코드로 촘촘한 격자에서 문까지 걸어가기, 벽·구석·가구 밀기, 모든 의자에서 일어서기를 검사
