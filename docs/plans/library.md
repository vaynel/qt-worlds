# 📚 이야기 도서관 기획안 (v2, 2026-11-12 · 사용자 방향 반영)

> **한 줄 요약:** 광장 옆 도서관에 들어가면, 사람들이 직접 쓴 **"하나님을 만난 이야기(간증)"**와 **신앙 생활 인증**이 책장에 꽂혀 있다. 읽고, 공감하고, 답장하며 **이야기가 이어지는 곳**.


## 0. ✅ 사용자 방향 (v2): 쓸 수 있는 글은 딱 2가지
1. **🙏 나의 하나님 이야기**: 지금까지 만난 하나님 이야기(간증)를 **직접** 쓴다
2. **📔 오늘의 일기 (자동 기록)**: QT 월드에서 한 일이 **하루 동안 자동으로 기록**되고, [오늘 일기 쓰기]를 누르면 **알아서 일기가 써져서** 도서관에 꽂힌다
   - 기록되는 것: 머문 시간, 📸 월드 안 스크린샷, 🙏 기도의 뜰에서 기도한 시간, 📖 오늘의 말씀과 묵상, 🏮 읽은 등불과 남긴 반응, 🔥 모닥불 나눔, 🎙️ 기도방, 🪑 앉은 곳, 🛍️ 빌린 소품 등
   - 자동으로 쓴 초안을 **내가 고치고 한 줄 덧붙여** 올린다
- 기존 v1의 "인증 5종류"는 **자동 일기와 스크린샷으로 대체**한다 (따로 인증을 쓰지 않음)

### 0-1. 자동 일기 설계 요약
- **발자취 기록:** 서버가 내 활동을 날짜별 이벤트로 저장한다 (나만 볼 수 있음). 끌 수 있고, 일기에 쓰이지 않은 기록은 30일 뒤 삭제
- **📸 스크린샷:** 월드 어디서나 카메라 버튼으로 찰칵. 하루 10장까지 오늘 앨범에 저장되고, 일기에 넣을 사진을 고른다 (게임 화면이라 실제 얼굴과 위치 정보가 없음)
- **일기 생성:** 1단계는 **문장 템플릿**으로 만든다 (외부 전송 없음). 2단계에서 AI로 더 자연스러운 글을 선택 사항으로 검토한다 (외부 전송이므로 동의와 개인정보처리방침 필요)
- **다른 사람 보호:** 일기에는 **다른 사람 이름을 기본으로 넣지 않는다** ("한 성도의 등불", "3명과 모닥불에"). 공개·실명 등불만 이름을 넣을지 선택 가능. 모닥불 채팅에서 **다른 사람이 한 말은 절대 넣지 않는다**
- **공개 범위:** 나만 / 모임 / 공개 (익명 공개 포함). 기본값은 검토 필요


## 0-2. ✅ 확정 (2026-11-12)
- 일기 생성은 **템플릿(정형 문장)으로만** 만든다. **AI는 사용하지 않는다** (비수익 운영이라 비용 부담. 외부 전송도 없음)
- 아래는 사용자가 따로 정하지 않아 **추천값으로 진행**한다 (나중에 바꿀 수 있음)
  - 이름: **이야기 도서관**
  - 일기 기본 공개 범위: **모임** (공개, 나만, 익명 공개도 선택 가능)
  - 📸 카메라 버튼: 화면 **오른쪽 아래** 작은 버튼 (조이스틱, 찬양 플레이어와 겹치지 않게)
  - 일기는 **언제든** 쓸 수 있고, **밤 9시 "오늘 일기 쓸까요?" 알림**은 선택 (기본 끔)
  - 답장 편지: **포함** (2단계에서 바로 이어서)
  - 간증은 **작성자가 지울 때까지 보관**, 일기도 같음. 일기에 쓰이지 않은 발자취와 스크린샷은 30일 뒤 삭제
- 개발 순서: **L-A** (도서관 건물과 내부, 발자취와 스크린샷, 두 가지 글 쓰기·읽기, 공감, 책갈피, 읽음 수, 신고와 관리, 법적 문서) → **L-B** (답장 편지 대화, 알림, 밤 일기 알림)

## 1. 왜 도서관인가
- **묵상(매일, 짧음)**과 **등불(3일, 사라짐)**은 흐르는 기록이다. **간증은 오래 남아야** 하고 다시 꺼내 읽혀야 한다
- 도서관은 **"조용히 남의 이야기를 읽는 곳"**이라 처음 온 사람도 부담 없이 머물 수 있다 (읽기만 해도 참여)
- 읽다 보면 "나도 써 볼까"로 이어진다

## 2. 공간 구성 (월드 안)
- **위치:** 중앙 광장 서북쪽, 기도의 뜰과 등불 언덕 사이의 작은 돌집. 이정표에 "📚 이야기 도서관" 추가
- **내부:** 여러 사람이 함께 있는 공간이다 (골방과 달리 서로 보임). 조용한 분위기
  - **서가(책장) 5개:** 주제별 (아래 3번)
  - **"오늘 꽂힌 책" 진열대:** 최근 이야기
  - **"인증 게시판" 벽:** 코르크 보드에 카드가 붙는 느낌
  - **열람 책상과 의자:** 앉아서 읽기 (벤치처럼 앉기)
  - **"쓰는 책상":** 여기서 "이야기 쓰기"를 시작
- 책장에서 책을 누르면 **책이 펼쳐지는 화면**으로 읽는다
- 밤에는 스탠드 불빛, 낮에는 창으로 햇빛

## 3. 콘텐츠 종류
### A. 📖 이야기 (간증): 긴 글
| 서가 | 예시 |
|---|---|
| 🌱 처음 만난 하나님 | 처음 믿게 된 이야기 |
| 🙏 기도 응답 | 기도가 응답된 이야기 (등불·기도 제목에서 이어 쓰기 가능) |
| 🌧️ 광야에서 | 힘든 시간에 만난 하나님 |
| 💌 감사 | 일상의 감사 |
| ✨ 말씀이 살아날 때 | 말씀이 삶에서 이루어진 순간 |

- **쓰기 도우미:** 빈 화면 대신 질문으로 안내한다 ("그때 어떤 상황이었나요?" → "하나님을 어떻게 만났나요?" → "지금 무엇이 달라졌나요?")
- 제목, 본문(최대 약 3,000자), 관련 성경 구절(선택), 서가 선택
- **공개 범위:** 공개 / 모임만 / **익명 공개** (등불처럼 서버에서 작성자 정보를 숨김)
- **임시 저장**하고 나중에 이어 쓸 수 있다

### B. ✅ 인증: 짧은 기록
| 인증 종류 | 예시 |
|---|---|
| 📖 QT 인증 | "오늘도 말씀 앞에" (QT 월드에서 묵상하면 자동 제안) |
| 📜 통독 인증 | "창세기 완독!" |
| ⛪ 예배 인증 | "주일 예배 다녀왔어요" |
| 🤝 섬김 인증 | 봉사, 나눔 |
| 🙌 응답 인증 | 기도가 응답됨 (→ 이야기로 이어 쓰기 버튼) |

- 짧은 글(200자) + **스티커 도장** (사진 대신, 아래 7번 참고)
- 인증 게시판 벽에 카드로 붙고, **7일 동안** 보인다 (본인 기록에는 계속 남음)

## 4. 소통 장치 (핵심)
| 장치 | 설명 |
|---|---|
| **💛 공감** | "은혜받았어요", "저도 그랬어요", "함께 기도해요" (한 번씩) |
| **✉️ 답장 편지** | 이야기 아래에 **짧은 편지(300자)**를 남긴다. 작성자가 다시 답할 수 있어서 **대화가 이어진다** |
| **🔖 책갈피** | 마음에 남은 이야기를 내 책장에 꽂아 둔다 (말씀 책의 "담아 둔 묵상"과 연결) |
| **🔔 알림** | 내 이야기에 공감이나 편지가 오면 알림 (설정에서 끄기 가능) |
| **📚 이어지는 이야기** | "이 이야기를 읽은 사람들이 함께 읽은 이야기", 같은 성경 구절의 다른 이야기 |
| **🎙️ 낭독 (2단계)** | 작성자가 자기 이야기를 목소리로 녹음 (관리 부담이 커서 나중에) |

## 5. 찾아 읽기
- **새로 꽂힌 책**, **오늘의 추천** (운영자가 고른 이야기), **많이 공감받은 책** (이번 주)
- 서가별, 성경 구절별 보기
- **나의 서재:** 내가 쓴 이야기, 인증, 책갈피

## 6. 안전과 관리 (꼭 필요)
- 신고: 부적절함, 개인정보 노출, 거짓, 광고 → 신고 **3건이면 자동 숨김**, 운영자 검토
- **답장 편지는 작성자가 지울 수 있고**, 이야기 작성자는 자기 글에 달린 편지를 숨길 수 있다
- 익명 이야기에는 "익명으로 쓰였어요" 표시. 서버에서 작성자 정보를 숨기고 운영자만 볼 수 있다
- 다른 사람의 실명, 연락처 같은 **개인정보 감지 경고** (전화번호 패턴 등)
- 관리자 화면: 신고된 이야기와 편지, "오늘의 추천" 지정

## 7. 사진 인증은?
- 사진은 **얼굴과 개인정보, 저작권, 부적절한 이미지** 관리 부담이 크다
- **1단계: 사진 없이** 글 + 스티커 도장으로 시작한다
- **2단계에서 검토:** 사진을 허용하되 **운영자 승인 후 공개**하거나, 모임 안에서만 공개

## 8. 기술 설계 (요약)
- 도서관 내부는 **여러 명이 함께 있는 실내 장면**이다 (골방처럼 별도 장면이지만 멀티플레이). 들어간 사람끼리 서로 보이고, 위치가 동기화된다
- **DB:** `stories`(이야기), `story_reactions`, `story_letters`(편지), `bookmarks`, `checkins`(인증), `story_reports`
- 개인정보처리방침과 약관에 추가: 이야기와 인증은 **삭제할 때까지 보관**, 탈퇴하면 모두 삭제, 내보내기에 포함
- 성능: 목록은 페이지 단위로 불러오고, 3D 책장의 책은 개수만큼 인스턴싱한다

## 9. 단계
| 단계 | 내용 |
|---|---|
| **L1** | 도서관 건물과 내부, 이야기 쓰기·읽기·공감·책갈피, 서가 5개, 신고·관리 |
| **L2** | 답장 편지(대화), 알림, 인증 게시판, 기도 응답 → 이야기 연결 |
| **L3** | 추천, 이어지는 이야기, 사진 인증(승인제) 검토, 낭독 검토 |

## 10. 결정이 필요한 것
1. 도서관 이름: "이야기 도서관" / "간증 도서관" / "은혜의 서재" / 기타
2. 서가 5개 구성이 괜찮은지 (넣고 뺄 것)
3. 인증 종류 5개가 괜찮은지
4. 사진 인증: 1단계에서 뺄지 (추천: 빼기)
5. 답장 편지를 L1에 넣을지 (소통이 목적이라면 L1에 넣는 것도 검토)
6. 이야기 보관: 영구(작성자가 지울 때까지)?
